## ✨ Fonctionnalités Majeures

### 1️⃣ **Assistant Vocal Flottant (Global)**
✅ **Accessibilité** : Présent en bas à droite sur toutes les pages du logiciel.  
✅ **Hautes Performances** : Utilise Whisper pour une transcription sans erreur même en milieu bruyant.  
✅ **Commandes Rapides** : 
- *"RDV demain 10h avec le client Sy"* -> Crée l'événement dans l'agenda.
- *"Ouvre le dossier TechCorp"* -> Bascule vers la page du dossier.
- *"Note : Relancer l'huissier"* -> Ajoute une tâche prioritaire.
- *"Rechercher jurisprudence licenciement"* -> Lance la recherche globale.

### 2️⃣ **Dictée Juridique Haute Précision**
✅ **Dictée Continue** : Pour rédiger de longs actes, conclusions ou courriers directement par la voix.  
✅ **Formatage IA** : Option pour nettoyer et formaliser le texte dicté (correction fautes, structure juridique).  
✅ **Multi-langue** : Support natif du Français et du Wolof (via Whisper).  

### 3️⃣ **Intégration API & Sécurité**
✅ **Confidentialité** : Traitement éphémère des flux audio.  
✅ **Infrastructure** : Routes API dédiées `/api/voice/transcribe` et `/api/voice/process-command`.

## 🧪 Comment tester

### 1. Activer l'Assistant Global
- Observez le bouton **Micro Bleu** en bas à droite de votre écran.
- Cliquez, parlez ("Ouvre les dossiers"), et observez la navigation automatique.

### 2. Tester la Dictée Longue
- Rendez-vous sur `http://localhost:3000/ai/voice`.
- Utilisez le grand module de dictée pour rédiger un paragraphe complet.
- Copiez le résultat en un clic pour vos actes.
